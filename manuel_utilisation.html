1. Contexte & objectif du projet

Qui est Amplitude Laser ?

Amplitude Laser est un fabricant français de lasers ultra-rapides (femtoseconde, picoseconde) destinés à des applications scientifiques, industrielles et médicales de haute précision. Ses clients sont principalement des laboratoires de recherche, des universités et des industriels de pointe à travers le monde.

Le problème de prospection B2B

Identifier des prospects qualifiés dans le domaine laser représente un travail manuel considérable : les appels à projets et les financements de recherche sont dispersés sur des dizaines de portails publics (NSF, NIH, CORDIS, UKRI, TED, NSERC, CIHR…), dans des formats hétérogènes et en plusieurs langues.

Sans outil dédié, un commercial doit consulter chaque base manuellement, lire les résumés de projets et évaluer leur pertinence pour Amplitude — un processus très chronophage et peu reproductible.

L'objectif de l'application

Laser Prospects automatise cette veille en agrégeant en temps réel les données de 7 sources publiques de financement de la recherche. Chaque projet est automatiquement scoré selon sa pertinence pour Amplitude (présence de mots-clés laser dans le titre et la description), puis présenté dans une interface de prospection commerciale.

En résumé, l'application permet de : • Collecter des centaines de projets de recherche financés en quelques minutes
• Les classer automatiquement par pertinence laser
• Filtrer, rechercher et exporter les prospects les plus intéressants
• Suivre l'état commercial de chaque contact (à contacter, contacté, pas intéressé)

5. Fonctionnalités détaillées

a. Rafraîchissement des données

Deux niveaux de rafraîchissement sont disponibles :

🔄 Refresh All (en-tête de page)

Lance la collecte complète sur toutes les sources simultanément. Durée : ~2 minutes. À utiliser pour une mise à jour globale de la base.

Refresh par onglet (🇺🇸 / 🇪🇺 / 📋 / 🍁)

Rafraîchit uniquement les sources de l'onglet concerné, sans modifier les autres. Plus rapide (~30 sec à 1 min). À utiliser pour cibler une zone géographique spécifique.

Après chaque rafraîchissement, la date et l'heure de la dernière mise à jour sont affichées sous le bouton Refresh All : Last updated: JJ/MM/AAAA at HH:MM.

b. Mots-clés de scoring

L'expander 🔑 Scoring Keywords permet de personnaliser les mots-clés utilisés pour calculer le score de pertinence de chaque prospect.

Chaque mot-clé est associé à un poids (1 à 10). Plus le poids est élevé, plus la présence du mot dans un projet augmente son score. Le titre compte double par rapport à la description.

  • ✅ Apply — applique les modifications et recalcule tous les scores immédiatement
  • 🔄 Default — restaure la liste de mots-clés par défaut d'Amplitude
  • Il est possible d'ajouter de nouvelles lignes ou de supprimer des mots-clés existants directement dans le tableau
⚠️ Important Les modifications de scoring sont appliquées à la session en cours uniquement. Elles ne modifient pas le fichier CSV source. Un rafraîchissement des données (Refresh) recharge les scores par défaut.
Amplitude Laser — Manuel d'utilisation Laser Prospects Section 5a–5b

c. Mots-clés d'exclusion

L'expander 🚫 Exclusion Keywords permet de masquer des projets non pertinents. Tout projet dont le titre ou la description contient un mot de cette liste est automatiquement exclu de l'affichage.

Format : un mot ou une expression par ligne. Les mots sont insensibles à la casse.

💡 Exemple d'utilisation Ajouter "printer", "imprimante", "inkjet" pour éliminer les projets liés à l'impression 3D qui utilisent le terme "laser" mais ne sont pas pertinents pour Amplitude.
  • ✅ Apply — active les nouveaux mots d'exclusion
  • 🔄 Default — restaure la liste d'exclusion par défaut

6. Algorithme de scoring

Chaque projet est scoré selon la présence de mots-clés dans son titre et sa description. La formule est :

Score = Σ (poids × 2) pour chaque mot-clé trouvé dans le titre
      + Σ (poids × 1) pour chaque mot-clé trouvé dans la description

Un projet doit avoir un score minimum de 5 pour apparaître dans l'application. Ce seuil est configurable via le filtre Minimum score.

💡 Exemple de calcul Un projet ayant "femtosecond laser" dans le titre et "ablation" dans la description obtiendrait :
Titre : 5×2 (femtosecond) + 2×2 (laser) = 14
Description : 4×1 (ablation) = 4
Score total = 18
